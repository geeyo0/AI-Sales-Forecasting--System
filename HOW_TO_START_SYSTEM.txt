REQUIREMENTS
============================================================

Before starting the system, make sure the following are installed:

1. XAMPP
2. Python
3. The project Python virtual environment (.venv)
4. A web browser such as Google Chrome or Microsoft Edge


============================================================
HOW TO START THE SYSTEM
============================================================

STEP 1: START THE DATABASE

1. Open the XAMPP Control Panel.
2. Find MySQL.
3. Click the Start button beside MySQL.
4. Wait until MySQL is highlighted in green.

Apache is not required because FoodCast uses Flask as its web
server. Only MySQL needs to be running in XAMPP.

DATABASE UPDATE FOR SALES TRANSACTIONS

If this is an existing FoodCast database, apply
database/migrations/add_sales_transactions.sql once with your MySQL
client before starting the updated application. New installations
should include the sales_transactions tables from database/sales.sql.

If this is an existing database, also apply
database/migrations/add_cashier_accounts.sql once to enable separate
cashier sign-ins. Managers can then create and disable cashier accounts
from the Cashiers page. New installations should use the updated
database/accounts.sql schema.

============================================================
EMAIL VERIFICATION
============================================================

Registration, MFA, password reset, and email-change verification
require SMTP credentials. Manager and administrator sign-ins use email
MFA. Cashier accounts are created by the manager and can sign in with
their username and password; managers can disable their access.

For Gmail, create a Google App Password and set these in the same
PowerShell window used to start Flask:

$env:FOODCAST_EMAIL = "your_sender_email@gmail.com"
$env:FOODCAST_EMAIL_APP_PASSWORD = "your_google_app_password"
$env:FOODCAST_SMTP_HOST = "smtp.gmail.com"
$env:FOODCAST_SMTP_PORT = "587"
$env:FOODCAST_SMTP_SECURITY = "starttls"

Then start (or restart) the Flask application in that window:

python -m flask --app app run --host 0.0.0.0 --port 5001

Use a Google App Password for FOODCAST_EMAIL_APP_PASSWORD.
Do not use the regular password of the Gmail account.

For another SMTP provider, use its server hostname and port. Use
FOODCAST_SMTP_SECURITY=starttls for STARTTLS (commonly port 587) or
FOODCAST_SMTP_SECURITY=ssl for implicit TLS (commonly port 465).
FOODCAST_SMTP_PASSWORD can be used instead of
FOODCAST_EMAIL_APP_PASSWORD for a provider's SMTP password.

For GitHub Codespaces, add FOODCAST_EMAIL,
FOODCAST_EMAIL_APP_PASSWORD (or FOODCAST_SMTP_PASSWORD),
FOODCAST_SMTP_HOST, FOODCAST_SMTP_PORT, and
FOODCAST_SMTP_SECURITY as Codespaces secrets in GitHub Settings.
Restart the Codespace so the secrets are added to its environment, then
restart Flask. Adding a secret does not update an already-running Flask
process.


============================================================
COMMON PROBLEMS
============================================================

PROBLEM:
The page cannot be opened.

SOLUTION:
Make sure the Flask terminal is still running and open:

http://127.0.0.1:5001


PROBLEM:
The system cannot connect to the database.

SOLUTION:
Open XAMPP and make sure MySQL is running.
If you are using VS Code or Codespaces, make sure a MySQL server is
available in that environment; the MySQL service on your own computer
is not reachable from the forwarded application.


PROBLEM:
A Python package is missing.

SOLUTION:
Run:

.\.venv\Scripts\python.exe -m pip install -r requirements.txt


PROBLEM:
Port 5001 is already in use.

SOLUTION:
Close the other FoodCast command window, or stop the old server
by pressing Ctrl+C.


PROBLEM:
Changes to CSS or JavaScript do not appear.

SOLUTION:
Refresh the browser using:

Ctrl+F5


PROBLEM:
Email verification cannot be sent.

SOLUTION:
Set FOODCAST_EMAIL and FOODCAST_EMAIL_APP_PASSWORD (or
FOODCAST_SMTP_PASSWORD) in the environment used to start Flask.
Check the SMTP host, port, and security mode for your provider, then
restart Flask. For Codespaces, add the values as Codespaces secrets and
restart the Codespace first. Do not disable email verification.
